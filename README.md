# 研究生通识课 AI 教育平台 · 静态展示版

这是「研究生通识课 AI 教育平台」的**纯静态展示版本**，用于部署到 GitHub Pages，作为大创申报的演示前端。

## 设计风格
学术专业风：蓝白主色 + 深色侧边栏，稳重清晰，贴近学堂在线 / 学习通等研究生学习平台。

## 技术说明
- 纯前端（原生 HTML / CSS / JS），**零构建**，改完直接部署，无需服务器。
- 所有数据读写统一走 `api.js` 这一层：当前用浏览器 `localStorage` 落地（刷新不丢），
  未来接入老师提供的后端时，只需替换 `api.js` 内部实现，UI 无需改动。

  - 教师：`teacher01`

## 目录结构
```
index.html      页面结构（登录壳 + 主应用壳）
styles.css      学术专业风样式
icons.js        内联 SVG 图标系统（无 CDN）
data.js         种子数据（课程 / 公告 / 名单 / 群聊等）
api.js          统一数据访问层（localStorage，可替换为后端）
app.js          学生端：概览 / 课程中心 / 课程详情 / AI课堂 / 讨论 / 群聊 / 学习小组 / 签到 / 学情看板 / 账号管理
teacher.js      教师端：学情概览 / 课程管理 / 章节作业 / 批改打分 / 学生名单 / 公告管理
assets/         讲解视频与课件（slide1~3.html）
fullstack/      带 FastAPI 后端的全栈源码（另一份，独立运行）
```

## 本地预览

```bash
python -m http.server 8099
# 浏览器打开 http://localhost:8099
```
